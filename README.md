# Оценка качества вина

Приложение оценивает вероятность хорошего вина по его характеристикам

Используется логистическая регрессия с `class_weight='balanced'`,
Порог по умолчанию равен **0.5**

## Запуск

Приложение проверено на *Python 3.13.9*

Нужно открыть терминал в папке `wine_app` и установить зависимости:

```bash
python -m pip install -r requirements.txt
```

Далее запустите приложение:

```bash
python -m streamlit run app.py
```

Вас либо автоматически перекинет в браузер, либо можете открыть адрес из терминала.
Для остановки приложения нужно нажать *Ctrl+C*

## Возможности

- Оценка одного вина
- Просмотр метрик и графиков при изменении порога
- Загрузка CSV с признаками вин и скачивание предсказаний
- Просмотр коэффициентов модели

CSV должен содержать те же столбцы признаков, что и test.csv, без столбца target

## Кэширование

Для модели используется `st.cache_resource`: он сохраняет один общий объект модели для повторного использования

Для таблицы и тестовых вероятностей используется `st.cache_data`:
он сохраняет результаты вычислений и возвращает их копии

При изменении порога тестовые вероятности берутся из кэша. Заново вычисляются предсказанные классы и метрики.

Без декоратора `joblib.load` загружал бы модель с диска при каждом изменении элементов интерфейса
